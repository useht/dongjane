# 동자네

> 갓바위 앞에서 함께 절하고 쉬어가는 포근한 월드, https://dongjane.com/ 에서 플레이하세요!

## 프로젝트 소개

동자네는 브라우저에서 열리는 3D 공유 월드예요. 팔공산 갓바위를 본뜬 야외 마당과 그 옆의 법당이 하나의 월드로 이어져 있고, 방문객은 어린 동자승이 되어 걸어 다니며 돗자리나 방석에 앉아 절을 올리고 쉬어갈 수 있어요. 한 월드에는 최대 100명이 함께 들어오고, 컴퓨터가 움직이는 동자승 50명도 법당에서 출발해 월드 곳곳을 거닐며 곁을 지켜요.

설치 없이 주소만 열면 되고, PWA라서 홈 화면에 설치할 수도 있어요. 화면은 PC와 휴대폰 모두에서 쓸 수 있게 만들어져 있어요.

## 주요 기능

**걷기와 시점**
- 키보드 WASD/방향키, 휴대폰은 화면 왼쪽 절반을 끌어서 쓰는 가상 조이스틱으로 걸어요.
- 바닥을 톡 치면 그 자리까지 걸어가요. 마당과 법당 사이는 문을 거쳐 길을 찾아가요.
- 끌어서 시점 돌리기, 휠/핀치로 확대와 축소, Q/E로 카메라 회전. 서 있을 때는 스페이스로 점프해요.

**법당과 마당**
- 마당(갓바위, 돗자리 50석)과 법당(방석 50석) 두 구역이 있어요. 법당은 정면 문으로 들어가고, 안으로 들어가면 카메라와 소리가 함께 바뀌어요.
- 접속하면 법당 안에서 시작해요. 법당 내부 모델은 용량이 커서 월드를 열 때 다른 모델과 함께 미리 받아 와요. 문으로 나가면 마당이에요.
- 마당 쪽에는 연등이 걸린 야외 무대가 있고, 화면에는 YouTube 영상이 임베드되어 재생돼요.

**절, 예불, 목탁**
- 자리에 가까이 가면 앉기 표시가 뜨고, 앉은 뒤에 절 버튼이나 스페이스로 절을 올려요. Esc로 일어서요.
- 30분마다 3분 동안 예불 시간이 열려요(한국 시간 기준). 시작할 때 종소리가 세 번 울려요.
- 장비 창에서 목탁이나 염불을 고르면 앉은 채로 목탁을 치거나 염불을 외울 수 있어요. 다른 방문객의 목탁 소리는 거리에 따라 작게 들려요.
- 근처 방문객이 절을 시작하면 "N번 동자님이 인사했어요" 알림이 떠요.

**소통**
- 이모티콘 8종을 머리 위 말풍선으로 보여줘요.
- 가까이 있는 방문객 머리 위에는 절 횟수에 따른 칭호가 보여요.

**퀘스트와 도감**
- 하루 3개의 퀘스트가 나와요(예: 특정 줄에서 절 N번, 예불 시간에 절 N번). 한국 시간 자정에 바뀌고 같은 날에는 모두에게 같아요.
- 누적 절 횟수에 따라 칭호 8단계(초발심부터 만배 법사까지)를 얻고, 도감에서 확인해요.
- 진행 상황과 도감은 이 기기의 localStorage에 저장돼요.

**휴대폰 화면과 HUD**
- 오른쪽 위 시계를 누르면 휴대폰 홈 화면이 열려요. 도감, 방문객 목록, 초대 링크 복사, 설정이 들어 있어요.
- 시계는 한국 시간 기준 하늘의 시각과 날씨(맑음, 흐림, 비, 눈)를 보여줘요. 하늘과 날씨는 서버 시간으로 계산해서 같은 월드 사람들은 같은 하늘을 봐요.

**여러 월드와 재접속**
- 월드마다 번호가 있고, 번호를 입력하거나 `?world=번호` 주소로 들어가요. 자리가 없으면 다른 월드로 안내해요.
- 가장 높은 번호의 월드에 90명이 모이면 다음 월드를 미리 열고, 혼자 남은 월드는 다른 월드로 합쳐요(이동 안내가 먼저 떠요).
- 연결이 끊겨도 서버가 3분 동안 자리를 지켜 주고, 클라이언트는 자동으로 다시 연결을 시도해요.
- 서버에 닿지 못하면 "혼자 월드에서 쉬기"로 같은 시뮬레이션을 브라우저 안에서 돌려요. 서버가 돌아오면 10초 카운트다운 뒤 원래 월드로 돌아가요.

**소리와 설정, 설치**
- 배경 소리와 효과음 크기를 따로 조절하고, 움직임 줄이기를 켤 수 있어요. 시스템의 "동작 줄이기" 설정을 기본값으로 따라가요.
- 기기 성능이 낮아 보이면 그림자 해상도, 낙엽과 비·눈 입자 수, 무대 영상 크기를 낮추고, 프레임이 길어지면 렌더 해상도도 자동으로 줄여요.
- 설치 가능한 브라우저에서는 설치 배너가 뜨고, iOS Safari에서는 "홈 화면에 추가" 안내가 떠요. 서비스 워커가 앱 파일을 캐시하고 새 버전이 나오면 자동으로 갱신해요.

## 저장소 구조

```
packages/client   Vite 클라이언트: 3D 월드, 화면 UI, 오디오, 네트워크, PWA 설정
packages/server   Colyseus 서버: 월드 방, 월드 배정, 빌드된 클라이언트 정적 서빙
packages/shared   서버와 클라이언트가 함께 쓰는 스키마, 메시지, 걷기/좌석/퀘스트/하늘 규칙, 시뮬레이션
packages/client/blender, scripts, assets   Blender 모델 스크립트(*.py), 에셋 빌드 스크립트, 동자승 모델 원본
```

각 패키지의 `test/` 폴더에 단위 테스트가 있고, 서버에는 실제 서버를 띄워 확인하는 통합 테스트도 있어요.

## 실행 방법

```sh
pnpm install     # 의존성 설치
pnpm dev         # 서버와 클라이언트 개발 서버를 함께 실행
pnpm build       # 클라이언트 타입 검사 후 packages/client/dist 로 빌드
pnpm start       # 서버 실행 (빌드된 클라이언트가 있으면 같이 서빙)
pnpm test        # vitest run
pnpm typecheck   # 모든 패키지 타입 검사
pnpm icons       # 브랜드 마크로 아이콘 PNG와 favicon 다시 만들기
pnpm assets      # Blender로 3D 모델 다시 만들기 (아래 참고)
```

`pnpm dev`를 실행하면 클라이언트는 `http://localhost:5173`, 서버는 2567번 포트에서 열려요. 개발 서버가 `/__server` 경로를 서버로 넘겨 주기 때문에 별도 설정이 필요 없어요. 배포할 때는 `pnpm build`로 클라이언트를 만든 뒤 `pnpm start` 한 번으로 페이지와 WebSocket을 같은 포트에서 내보내요.

환경 변수는 코드가 실제로 읽는 것만 적었어요.

| 변수 | 읽는 곳 | 하는 일 |
| --- | --- | --- |
| `PORT` | 서버, Vite 개발 서버 | 서버가 열릴 포트(기본 2567). 개발 서버의 프록시 대상 포트도 이 값을 따라요. |
| `CLIENT_DIR` | 서버 | 서빙할 클라이언트 빌드 폴더(기본 `packages/client/dist`). 폴더에 `index.html`이 없으면 서버만 실행돼요. |
| `VITE_SERVER_URL` | 클라이언트(빌드 시점) | 서버 주소를 직접 지정해요. `ws://`, `wss://`로 적어도 돼요. 비워 두면 개발 중에는 `/__server` 프록시, 배포 후에는 페이지와 같은 주소를 써요. |
| `BLENDER_BIN` | `pnpm assets` | Blender 실행 파일 경로. |
| `MONK_PREVIEW_DIR` | `build_monk.py` | 동자승 모델을 만들 때 미리보기 PNG를 저장할 폴더(기본은 임시 폴더). |

주소에 `?debug`를 붙이면 프레임과 드로 콜 같은 성능 정보가 화면에 나와요.

## 에셋 빌드

월드의 3D 모델(`packages/client/src/assets/models/*.glb`)은 Blender 스크립트로 만들어 저장소에 함께 올려 둔 결과물이에요. **게임을 실행하거나 개발하는 데는 Blender가 필요 없고, 모델을 다시 만들 때만 필요해요.**

`pnpm assets`는 `packages/client/scripts/build-assets.ts`를 실행해요.

1. Blender 실행 파일을 찾아요. `BLENDER_BIN`, Windows 기본 경로 `C:/Program Files/Blender Foundation/Blender 5.2/blender.exe`, PATH의 `blender` 순서예요. 모두 없으면 오류로 멈춰요.
2. 월드 규격(좌석 배치, 법당 치수, 색 등)을 코드에서 읽어 JSON으로 넘겨요. Blender 스크립트는 치수나 색을 따로 정하지 않아서 모델이 코드와 어긋나지 않아요.
3. 백그라운드로 `blender/build.py`를 돌려 갓바위, 부처상, 마당과 산, 무대, 법당 모델을 `src/assets/models/`에 써요.
4. 스크립트와 입력 데이터의 해시, 결과 파일의 해시를 `stamp.json`에 기록해요. 테스트가 이 해시를 확인하기 때문에, 스크립트나 월드 규격을 고쳤는데 `pnpm assets`를 다시 돌리지 않으면 `pnpm test`가 실패해요.

동자승 모델은 `pnpm assets`와 별개예요. `packages/client/assets/monk/build_monk.py`를 Blender로 직접 실행해 `monk.glb`와 `monk-rig.json`을 만들어요(실행 방법은 파일 맨 위 설명에 있어요).

## 에셋 출처와 라이선스

자세한 출처, 변경 내용, 해시는 `packages/client/blender/sources/sources.md`와 `packages/client/src/assets/audio/sources.md`에 있어요. 게임 안의 설정 > "소리와 모델 출처"에도 같은 크레딧이 표시돼요.

| 에셋 | 출처 | 라이선스 |
| --- | --- | --- |
| 바위, 돌길, 돗자리, 카지노 카펫 질감 (이미지 7장, 512px로 줄임) | Poly Haven (카펫은 ambientCG Carpet013) | CC0 1.0 (표시 의무 없음, 출처는 sources.md에 적어 둠) |
| 부처상 (갓바위와 법당 불단) | 국립중앙박물관 석조여래좌상(부여 군수리) 3D 스캔 | 공공누리 제1유형, 출처표시 |
| 법당 염불 소리 (`sutra.mp3`) | 공유마당 「염불소리1」 | CC BY (출처표시, 앞뒤를 자르고 소리 크기 조정) |
| 목탁 소리 (`mokt.mp3`) | Freesound 607215 「Mokugyo.wav」 (jonopodmore), 한 번 치는 소리만 잘라 썼어요. 자세한 내용은 `audio/sources.md` | CC0 (표시 의무 없음) |
| 카지노 효과음 (`coin.mp3`, `click.mp3`, `jackpot.mp3`) | Freesound 510735 「Coin Drop」 (HoseNoseSounds), 538727 「Button Click」 (AndrewEathan), 860886 「Jackpot jingle」 (Johnmode), 필요한 부분만 잘라 썼어요. 자세한 내용은 `audio/sources.md` | CC0 (표시 의무 없음) |
| 야외 무대 영상 | YouTube 임베드 (저장소에 파일 없음) | YouTube 플레이어로 재생하며, 영상의 사용 권한이나 임베드 허용은 서비스 운영자가 따로 확인해야 해요 |

- 부처상은 점 수를 줄이고 빛과 그림자를 새로 입힌 모델이고, 게임에서 갓바위에서는 화강암색, 법당에서는 금색으로 칠해요. 박물관은 지정문화유산의 실물 복제품을 만들려면 별도 허가가 필요하다고 안내하고 있어요. 이 게임은 화면에만 보여 주지만, 모델을 출력하거나 주조하려면 먼저 박물관에 문의해야 해요.
- 갓 모양 돌, 받침대, 공양물, 소나무와 단풍나무는 스캔이나 사진을 따라 그리지 않고 Blender 스크립트로 직접 모델링했어요. 법당 건물, 무대, 카지노 건물과 기계도 같은 방식으로 만들었어요. 슬롯머신 그림 8장(`public/casino/symbols/`)은 이 프로젝트를 위해 이미지 생성 모델로 그렸고 외부 출처가 없어요. 동자승은 참고 사진의 비율을 맞춰 스크립트로 모델링했고, 그 사진은 저장소에 들어 있지 않아요.
- 앱 아이콘은 `packages/client/scripts/brand-mark.ts`의 SVG에서 `pnpm icons`로 만들어요.
